# NetGuard Marine: выпуски

**Русский** · [English](#netguard-marine-releases)

Здесь лежат только установщики NetGuard Marine и описания выпусков. Код программы хранится
в отдельном закрытом репозитории.

**[Скачать последнюю версию](https://github.com/KirkRo/NetGuard-releases/releases/latest)**:
файл `NetGuardSetup.exe`.

NetGuard Marine контролирует и жёстко ограничивает интернет-трафик Windows на
лимитированных каналах: спутник на судне, мобильный модем, тариф с оплатой за мегабайт.
Программа блокирует фоновые загрузки до того, как они начнутся, показывает расход каждой
программы, считает квоту и деньги. Нужна Windows 10 версии 1809 или новее, x64.

Раз в сутки программа заглядывает сюда, чтобы узнать, не вышла ли новая версия. Это один
запрос, около 10 КБ, и его можно выключить в «Настройках». Установщик скачивается только
по кнопке и запускается, только если его размер и SHA-256 совпали с `update.txt` из того
же выпуска, подписанным ключом автора.

Лицензионный ключ можно получить в Telegram: **@kirk_ro**. Цены и условия покупки:

# NetGuard Marine releases

[Русский](#netguard-marine-выпуски) · **English**

This repository holds only the NetGuard Marine installers and release notes. The source
code is kept in a separate private repository.

**[Download the latest version](https://github.com/KirkRo/NetGuard-releases/releases/latest)**:
the file is `NetGuardSetup.exe`.

NetGuard Marine controls Windows internet traffic with hard limits on metered links such as
satellite internet on a ship, a mobile modem or a plan billed per megabyte. It blocks
background downloads before they start, shows how much each program uses, and keeps track
of your quota and what it costs. It needs Windows 10 version 1809 or later, x64. The
interface is in Russian.

Once a day the program looks here to see whether a new version is out. That is one request
of about 10 KB, and you can turn it off in the settings. The installer is downloaded only
when you press the button, and it runs only if its size and SHA-256 match `update.txt` from
the same release, which is signed with the author's key.

[kirkro.github.io/NetGuard-releases](https://kirkro.github.io/NetGuard-releases/).
