Вопросы

Перед покупкой.

Программа сама ходит в интернет?
Только раз в сутки проверяет обновление, около 10 КБ, и это отключается. Ключ проверяется на вашем компьютере, телеметрии нет.
В Windows уже есть лимитное подключение. Зачем NetGuard?
Лимитное подключение Windows только подсказка: его слушают Windows Update и программы Microsoft, остальные обычно нет. NetGuard запрещает трафик по программам и считает мегабайты и деньги. На судовом интернете и телефоне он сам включает лимитное подключение Windows, а прежнее значение потом возвращает.
Можно перенести ключ на другой компьютер?
Ключ работает на одном компьютере. Если меняете компьютер, напишите в Telegram.
